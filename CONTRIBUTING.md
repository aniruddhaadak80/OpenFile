# Contributing to OpenFile

Thanks for helping make private file tools better for everyone!

1. Fork and clone, then `npm install` and `npm run dev`.
2. Read [docs/TOOL_GUIDE.md](docs/TOOL_GUIDE.md) for the tool conventions and UI kit.
3. Keep everything client-side — PRs that upload user files to a server will not be merged.
4. Run `npm run typecheck && npm run build` before opening a PR.
5. Describe what you changed and add a screenshot or GIF for UI changes.

Bug reports and tool ideas are welcome as GitHub issues.
