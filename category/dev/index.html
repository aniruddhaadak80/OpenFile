Developer

JSON, JWT, regex, hashes, cURL and more. 65 free tools that run 100% in your browser.

  • Password Generator: Strong random passwords and passphrases with strength meter.
  • QR Code Generator: QR codes for links, Wi-Fi, vCards and text with colors and logo.
  • QR Code Scanner: Scan QR codes from your camera or an image.
  • Barcode Generator: CODE128, EAN-13, UPC, CODE39 and more as PNG/SVG.
  • Regex Tester: Test regular expressions with live highlighting and groups.
  • Regex Builder: Build regular expressions from plain-language blocks.
  • Base64 Encode/Decode: Encode or decode Base64 text and files.
  • URL Encode/Decode: Encode/decode URLs and parse query strings.
  • cURL to Code: Convert cURL to JavaScript, Python, Go, Rust, PHP, Java and more.
  • Timestamp Converter: Unix epoch ⇄ human dates across time zones.
  • Cron Explainer: Explain cron expressions and preview next run times.
  • YAML ⇄ JSON: Convert between YAML and JSON with validation.
  • SQL Formatter: Beautify SQL for many dialects.
  • ERD Studio: Design database schemas and export SQL, Prisma and Drizzle.
  • HTML Entities: Escape and unescape HTML entities.
  • Number Base Converter: Binary, octal, decimal and hex conversion.

  • Classic Ciphers & Codes: Caesar, ROT13, ROT47, Vigenère, Atbash, Affine, Morse, Bacon, rail fence, XOR, NATO, Braille and more.
  • Encoding Toolbox (Recipe Chains): Chain encodings: Base64, hex, Base32/58/62/85, gzip, URL, punycode, quoted-printable, MessagePack, protobuf and more.
  • String Escape / Unescape: Escape or unescape text for JSON, JavaScript, Java, C#, Python, C, Go, SQL, CSV, regex, shell and HTML.
  • IP Subnet Calculator: IPv4 and IPv6 CIDR calculator, subnet splitter, range to CIDR and ULA generator.
  • MAC Address Lookup & Generator: Find the vendor of a MAC address offline, convert formats and generate random MACs.
  • Device & User-Agent Info: See your browser, OS, screen, GPU and supported features, or parse any user-agent string.
  • Meta / Open Graph Tag Generator: Write SEO, Open Graph and X card tags with live search and social previews.
  • HTTP Status Codes: Searchable list of HTTP status codes with plain meanings and when to use each.
  • MIME Type Lookup: Find the MIME type for a file extension, or the extensions for a MIME type.
  • Keycode Info: Press any key to see event.key, event.code, keyCode, location and modifiers.
  • Basic Auth Header Generator: Build or decode HTTP Authorization: Basic headers, with curl and fetch examples.
  • HTML WYSIWYG Editor: Write rich text like a word processor and get clean HTML you can copy or download.
  • docker run to Compose: Turn one or more docker run commands into a docker compose YAML file.
  • chmod Calculator: Convert Unix permissions between checkboxes, octal (755) and symbolic (rwxr-xr-x).
  • Phone Number Parser: Parse, validate and format international phone numbers, in bulk or found inside text.
  • IBAN & BIC Validator: Validate and parse IBAN and BIC/SWIFT codes offline, one at a time or in bulk.
  • File Type Identifier: Find out what a file really is from its magic bytes, with entropy and header view.

  • Dummy File Generator: Make test files of an exact size: random or zero bytes, text, CSV, JSON, and valid PDF, PNG, WAV and ZIP files.

  • .env Converter & Checker: Convert .env files to JSON, YAML, Docker Compose, Kubernetes ConfigMap or Secret, and find missing keys.
