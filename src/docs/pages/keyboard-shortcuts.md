# Keyboard shortcuts

OpenFile is designed to be driven from the keyboard. On macOS, use <kbd>⌘</kbd> wherever <kbd>Ctrl</kbd> is listed.

## Everywhere

| Action | Shortcut |
| --- | --- |
| Open the command palette (search tools and pages) | <kbd>Ctrl</kbd> + <kbd>K</kbd> |
| Close a dialog or the palette | <kbd>Esc</kbd> |
| Move between buttons and fields | <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> |
| Open a file picker on a focused drop area | <kbd>Enter</kbd> or <kbd>Space</kbd> |

## Command palette

| Action | Shortcut |
| --- | --- |
| Move through results | <kbd>↑</kbd> / <kbd>↓</kbd> |
| Open the highlighted result | <kbd>Enter</kbd> |
| Close | <kbd>Esc</kbd> |

The palette searches tool names, descriptions, categories and tags, plus pages such as Docs, History, Settings and Changelog.

## Docs

| Action | Shortcut |
| --- | --- |
| Focus the docs search | <kbd>/</kbd> |
| Move through search results | <kbd>↑</kbd> / <kbd>↓</kbd> |
| Open a result | <kbd>Enter</kbd> |
| Clear search | <kbd>Esc</kbd> |

## Home page search

Type in the hero search box and press <kbd>Enter</kbd> to open the best match.

## Sketch whiteboard

The [Sketch whiteboard](/sketch-board) has the richest set of shortcuts. Press <kbd>?</kbd> on the board to see them in place. The full list is in the [Sketch board guide](/docs/sketch-board#keyboard-shortcuts).

## Tool-specific shortcuts

Several editors respond to the keyboard while they have focus, for example the PDF editor, PDF reader, Organize PDF, Sign PDF, Redact PDF, Add Text to Image, the audio editor, voice recorder, video trimmer, gradient generator and ERD Studio. Hover a button to see its shortcut in the tooltip.
