# Getting started

OpenFile is a free, open-source workbench of **{{TOOL_COUNT}} file tools** for PDFs, images, video, audio, data and code. Every tool runs **inside your browser tab**. Files are never uploaded, there is no account to create, and there are no limits or watermarks.

> [!TIP]
> Press <kbd>Ctrl</kbd> + <kbd>K</kbd> (or <kbd>⌘</kbd> + <kbd>K</kbd> on macOS) anywhere to search every tool and page.

## Use your first tool

1. Find a tool. Browse [All tools](/tools), pick a category, or search with <kbd>Ctrl</kbd> + <kbd>K</kbd>.
2. Drop a file onto the drop area, or click it to choose a file. Many tools accept several files at once.
3. Adjust the options in the side panel. Most tools show a live preview.
4. Press the main action button and download the result. Batches come as a ZIP.

Your original files are never modified. You always get a new copy.

## Smart drop on the home page

Not sure which tool you need? Drop any file onto the **Smart drop** box on the [home page](/). OpenFile detects the file type, suggests the tools that fit, and opens the one you pick with the file already loaded.

## Save your favorite tools

Click the **star** on any tool card or the **Save** button on a tool page. Favorites and recently used tools appear at the top of the home page and on [All tools](/tools). Your [History](/history) page shows what you opened and downloaded. All of this is stored only in your browser. See [Favorites, history & settings](/docs/local-data).

## Install it as an app

OpenFile is a Progressive Web App. In Chrome or Edge, use the **Install** icon in the address bar; on iPhone and iPad, use **Share → Add to Home Screen**. The installed app opens in its own window and works offline.

## Work offline

A service worker caches the app shell, the tool code you have used, and the engines they downloaded. After a first visit you can disconnect from the internet and keep working. Tools that need an engine you have never loaded (for example the AI models) need a connection the first time.

## Batch work and whiteboards

- **[Workspace](/workspace)** chains steps such as *resize → watermark → convert* into a recipe and runs it on hundreds of files. See [Workspace pipelines](/docs/workspace).
- **[Sketch whiteboard](/sketch-board)** is an infinite canvas for diagrams, notes and presentations. See [Sketch board](/docs/sketch-board).
