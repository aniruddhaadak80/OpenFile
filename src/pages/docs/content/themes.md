# Themes and accessibility

OpenFile should be comfortable to use for a long session, in any light, with any input. Everything on this page is set in [Settings](/settings) or the theme menu in the header, and saved in this browser.

## Themes

There are {{THEME_COUNT}} themes: {{THEME_LIST}}. **System** follows your operating system and switches live when it does. **Black** is pure black, which saves power on OLED screens.

## Accent colors

Pick one of {{ACCENT_COUNT}} accents. It colors buttons, links, focus rings and highlights across the whole app, including these docs.

::component accents

## Fonts, density and corners

- **Font**: {{FONT_LIST}}.
- **Density**: comfortable or compact, for more on screen at once.
- **Corners**: rounded or sharp.

## Reduced motion

Motion follows your system setting by default. You can force it off or on in Settings under motion. With reduced motion, page transitions and the hero animation are reduced or switched off, smooth scrolling is turned off, and these docs jump straight to a section instead of scrolling.

## Keyboard and screen readers

- Every control can be reached with <kbd>Tab</kbd> and shows a clear focus ring in your accent color.
- Drop areas open the file picker with <kbd>Enter</kbd> or <kbd>Space</kbd>.
- Dialogs close with <kbd>Esc</kbd>, and the command palette and docs search are fully keyboard driven. See [shortcuts](/docs/keyboard-shortcuts).
- Icons that act as buttons have text labels for screen readers, and tab lists in these docs use proper tab roles with arrow-key navigation.

## Contrast and color

Text colors are chosen to stay readable on every theme. If you work with color yourself, the Design category has a contrast checker and a color blindness simulator.

> [!TIP]
> Your theme, accent and the rest of your settings can be exported to a file in Settings and imported on another device.
