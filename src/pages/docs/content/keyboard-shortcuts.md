# Command palette and shortcuts

OpenFile is built to be driven from the keyboard. On a Mac, use <kbd>Cmd</kbd> wherever <kbd>Ctrl</kbd> is listed. Single-key shortcuts are ignored while you type in a field. Press <kbd>?</kbd> anywhere to see the app shortcuts in a panel.

> The tables on this page are generated from the same shortcut lists the app uses, so they cannot drift out of date. There are {{SHORTCUT_COUNT}} app shortcuts and {{SKETCH_SHORTCUT_COUNT}} Sketch board shortcuts.

## Command palette

Press <kbd>Ctrl</kbd> + <kbd>K</kbd> to open the command palette. It searches every tool by name, description, category and tags, plus the main pages and these docs.

| Action | Keys |
| --- | --- |
| Open or close the palette | <kbd>Ctrl</kbd> + <kbd>K</kbd> |
| Move through results | <kbd>Up</kbd> and <kbd>Down</kbd> |
| Open the highlighted result | <kbd>Enter</kbd> |
| Close | <kbd>Esc</kbd> |

Type a few words, for example `pdf sign` or `video gif`. Every word has to match somewhere, and tools whose name starts with what you typed come first.
